Informe de Cambios del Proyecto

Fecha: 12 de diciembre de 2025

feat(seeding): Refactor completo del sistema de seeding de datos

Descripción General

Se ha realizado una refactorización completa del sistema de seeding de la base de datos para mejorar la modularidad, mantenibilidad y facilitar el desarrollo y las pruebas.

Cambios Principales

  • Scripts de Seeding en TypeScript: Todos los scripts de seeding han sido migrados de JavaScript a TypeScript (create_users.ts, create-shifts.ts), introduciendo tipado estático para mayor seguridad y claridad.
  • Nuevos Scripts Modulares: Se han creado scripts específicos para diferentes tareas:
    • clean-db.ts: Limpia la base de datos antes de la siembra.
    • generate_seed_data.js: Genera los datos de prueba y los guarda en archivos JSON.
    • verify-seed-data.ts: Verifica la integridad de los datos después de la siembra.
  • Centralización de Datos: Los datos de seeding para usuarios y turnos se han centralizado en el directorio seeds/ (users.json, shifts.json`), reemplazando la antigua ubicación en mocks/.
  • Actualización del Flujo de Reinicio: El script restart-project.js ha sido actualizado para orquestar la ejecución de los nuevos scripts de seeding en el orden correcto.
  • Configuración de TypeScript: Se ha añadido un tsconfig.json al directorio scripts/ para la compilación de los nuevos scripts.

Razonamiento del Cambio

Este refactor era necesario para abordar las limitaciones del sistema anterior, como la baja mantenibilidad de los scripts monolíticos, la falta de seguridad de tipos y la gestión descentralizada de los datos de prueba. El nuevo sistema es más robusto, flexible y se alinea con las mejores prácticas del proyecto, promoviendo un desarrollo más ágil y seguro.
